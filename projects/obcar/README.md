# OBcar Project

沖繩租賃車影像專案。為 23 款車各製作兩種約 30 秒的影片：車輛固定、攝影機在真實空間移動的完整 360°航拍，以及車輛在沖繩海邊道路正常行駛的無人機跟拍。每種影片都交付 16:9 與 9:16，因此共有 **46 個影片概念、92 個規格成片**。以 Google Flow Lite 製作時，每支成片由 3 段 10 秒素材組成；360°另用 7 個固定角度作身分與場景連續性參考。

## 完成定義

每款車必須依序通過：實車身分鎖定 → 主場景定錨圖 → 7 個一致角度 → 3 段 10 秒完整 360° clip → 3 張海邊道路定格圖 → 3 段 10 秒海邊跟拍 → 16:9／9:16 裁切與原生重構判定 → 車款一致性 QA → 成片輸出。正式逐車完成表與 Freed 三代 Demo Prompt 都在 Saidio 的「產線 → OBcar」；靜態資料源是 [`data/obcar.json`](../../data/obcar.json)，由 [`build_obcar_data.py`](../../scripts/build_obcar_data.py) 產生。通用長版說明仍保留在 [`PROMPTS.md`](PROMPTS.md)。

360°片的物理原則是「車與地面接觸點完全鎖定，只有攝影機移動」；海邊片則相反，車輛沿正確的左側車道前進，攝影機平滑追蹤。兩條片都不得用數位縮放冒充實體運鏡，也不得讓車身、輪圈、燈具、世代或套件在幀間變形。

## 每款車的標準工作包

1. 收齊最低參考組：前左、正側、後左、正後、輪圈、車頭燈組、車尾燈組；記錄車色、年式、世代、套件及座椅數。
2. 先生成一張主場景定錨圖。批准後，沿「前左 → 左側 → 後左 → 正後 → 後右 → 右側 → 前右」逐張產生，下一張同時帶入上一張批准圖。
3. 只在輪胎接觸點、停車線、車影與車頭方位一致時，才把角度放進同一段首尾幀。完整 360°分為三段：01前左→03後左（經左側）、03後左→05後右（經車尾）、05後右→01前左（經右側與車頭），每段 10 秒。
4. 海邊片先批准三張定格圖，再各自動畫化 10 秒：高空接近、海側平行跟拍、低空後方拉遠。依序剪接後約 30 秒。
5. QA 逐幀檢查車身比例、燈具、輪圈、門縫、徽章、車牌、陰影、車道方向、視差和背景連續性。任何一項變形都退回單段重生，不用錯誤片段硬剪。

## 命名規則

每款車使用 `NN-slug/` 資料夾，輸出建議為 `NN-slug_360_master_v01.mp4` 與 `NN-slug_coast_master_v01.mp4`。中間檔以 `anchor`、`angle-01` 至 `angle-07`、`360-clip-01` 至 `360-clip-03`、`coast-still`、`coast-clip` 命名，避免日後無法辨識首尾幀關係。
