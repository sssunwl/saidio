# OBcar Project

沖繩租賃車影像專案。為 23 款車各製作兩種約 30 秒的影片：車輛固定、攝影機在真實空間移動的 360°航拍，以及車輛在沖繩海邊道路正常行駛的無人機跟拍。每種都要 16:9 與 9:16，共 **46 個影片概念、92 個規格成片**。用 Google Flow Lite 製作，每支成片由 3 段 10 秒素材組成。

Prompt 架構見 [`PROMPTS.md`](PROMPTS.md)；可複製的 Prompt 在 Saidio「產線 → OBcar」，靜態資料源是 [`data/obcar.json`](../../data/obcar.json)，由 [`build_obcar_data.py`](../../scripts/build_obcar_data.py) 產生。車款主檔 [`vehicles.json`](vehicles.json) 也由同一支腳本導出。

## 每台車的標準工作包

1. **鎖車款**：確認世代／年式／套件，寫進腳本的 `model`；收齊實車照（前左、正側、後左、正後、輪圈、頭燈、尾燈）。沒有實車照不開工。
2. **A01 停車定錨圖**（16:9）。批准條件：車款身分正確、車身平行停車格、四輪在格內、白線不穿車底、前輪正直、四周乾淨。
3. **P1 → P2 → P3**：各 8–10 秒。P1 首幀＝批准的 A01，P2/P3 首幀＝上一段尾幀（Flow 按「延伸」）。先只做 P1，**先看最後 2 秒**（疊影、淡出、車頭換邊、車自己挪位都出在這裡），再確認車沒轉、輪胎沒滑、背景有真實視差，才往下。
4. **R01a/b/c 海邊定格圖**：高空遠景、海側平行、低空後方，同一天光同一段海岸。批准前先做**錯邊三連檢**：海與護欄在車左（從車後看＝海在畫面左）、車在靠海的左車道且沒壓中線、方向盤在右。任一條不過就重下，不要用左右鏡像救。批准後才動畫化成 **R02a/b/c**。
5. **9:16**：用已批准的 16:9 當場景參考，原生重生 4 張圖 + 6 段片。不裁切、不外擴。
6. **QA**：車身比例、燈具、輪圈、門縫、徽章、車牌、陰影、車道方向、視差、直式 4:5 安全區。任何一項變形就退回單段重生，不要拿壞片硬剪。

每比例 **4 圖 + 6 片**。360°片的物理原則是「車與地面接觸點鎖死，只有攝影機移動」；海邊片相反，車沿靠海的左側車道前進、攝影機平滑追蹤。兩者都不得用數位縮放冒充實體運鏡。日本是左側通行＋右駕，這條寫死在 Prompt 裡（見 [`PROMPTS.md`](PROMPTS.md) 的「日本鐵則」），全車隊共用同一段規則。

## 命名規則

每款車用 `NN-slug/` 資料夾。成片 `NN-slug_360_master_v01.mp4`、`NN-slug_coast_master_v01.mp4`；中間檔用 `A01`、`P1`–`P3`、`R01a`–`R01c`、`R02a`–`R02c`，前綴 `L`（16:9）或 `V`（9:16），例如 `L_A01_v2.png`。
